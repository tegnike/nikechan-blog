# デザインシステム

## ホバーのルール

押せる部品にマウスを乗せたときの動きは、部品の種類ごとに1つに決めている。
新しい部品を作るときは、下の表のどれに当たるかを先に決める。

| 部品 | ホバーの動き | 例 |
|---|---|---|
| ボタン | 濃紺（`--nk-ink`）で塗りつぶし、文字を白にする。位置と大きさは変えない | `design-action-button`、ページ送り、コピー、色付きの丸ボタン |
| すでに塗ってあるボタン（濃紺、または濃い背景上の白） | ピンク（`--nk-pink`）で塗りつぶす | `nk-btn`、アバウトの主ボタン、メールボタン |
| 濃い背景・色付き背景の上のボタン | 白で塗りつぶし、文字を濃紺にする。背景と同じ色では塗らない | `nk-dhero__links`、依頼の受付の連絡先、ピンク帯（`nk-create`）のボタン |
| カード（面全体がリンク） | 上に4px浮く。色は変えない | 記事カード、OGPカード、ギャラリーの画像、キャラクター切替 |
| 文中のリンク | 下線だけ。色は変えない | 記事の目次、著者名 |
| 選択中の切替・現在地 | 動かさない | ギャラリー切替、ガイドラインのタブ |

### 実装

- 定義は `src/styles/redesign.css` 末尾の「ホバーのルール」にまとめてある。部品ごとに個別のホバーを書かない。
- CSSのクラスを持つ部品は、そのセレクタを「ホバーのルール」の一覧に足す。
- Tailwindで直接組んだ部品には、ボタンなら `nk-hover-fill`、カードなら `nk-hover-lift` を付ける。
- パネル（`glass-panel`）内のリンクは旧スタイルでボタンの見た目になる。文中に置くリンクには `nk-text-link` を付けて下線のリンクに戻す。
- 拡大（`hover:scale-*`）、影の追加、斜めにずらす動きは使わない。

### ルールの対象外

次の部品は役割が違うので、それぞれ固有の動きのままにしている。

- ヘッダー・フッターのナビゲーション、キャラクターページのサブナビ
- トップページの一覧行（お知らせ、支援窓口）と記事タイル（画像の拡大と下線）
- コードブロックのコピーボタン
- `/world` の惑星
