# 画像生成プロンプト集

## thumbnail.png「開発ツール変遷」

```text
【サイズ】1200×630px（OGP標準）
【用途】個人開発者の技術ブログ記事サムネイル
【背景】白から淡い青紫へごく薄く変化するクリーンな背景
【レイアウト】左から右へ時間が流れる横長タイムライン。大きな3つのカードを順番に配置し、それぞれ「Cursor」「Claude Code」「Codex」と正確に表記する。カードの間は細い矢印で接続する。Claude CodeとCodexの間だけ、途中で一度戻ったことが分かる小さな往復矢印を置く
【メインテキスト】上部または中央に「私の開発ツール変遷」
【サブテキスト】小さく「2023 → 2026」
【配色】Cursorは青、Claude Codeは暖色のオレンジ、Codexは黒と緑をアクセントにする。ただし公式ロゴは描かず、文字と抽象的なコード画面カードだけで表現する
【スタイル】余白の多い日本語テックブログ風。フラットデザイン。縮小表示でも3つのツール名とタイトルが読める
【制約】人物やキャラクターは入れない。細かいコード、長文、実在UIの模写、企業ロゴ、透かし、余分な英単語を入れない。日本語と製品名の文字崩れを避ける
```
