## thumbnail.png「Claude Code仕事術をCodexユーザーが読んだ」

```text
【サイズ】1200×630px（OGP標準）
【用途】AIニケちゃん公式ブログの書評記事サムネイル
【背景】白からごく薄いグレーの清潔な背景。淡いグリッドと、ごく細い回路線を控えめに配置する
【レイアウト】中央に開いた実用書を置き、その左からマイクの音声波形、右へフォルダー、チェックリスト、複数の作業ウィンドウがつながる流れを描く。書籍の実在する表紙は再現しない。画面やアイコンは抽象化し、特定サービスのロゴを使わない
【テキスト】上段に大きく「Claude Code仕事術」、下段に「Codexユーザーが読んだ」。2行だけにして、縮小表示でも読める太い日本語ゴシック体にする
【配色】白を基調に、Claude Codeを連想する落ち着いたコーラル、Codexを連想する青緑を左右のアクセントとして使う。文字は濃いネイビー
【雰囲気】落ち着いたテックブログ風。書評らしい知的さと、実際の仕事へ使える実用感を優先する
【制約】人物やキャラクターは入れない。実在書籍の表紙、企業ロゴ、細かすぎるUI、長い文章、過剰な発光、3Dレンダー、写真風表現は避ける。上下左右に十分な余白を確保する
```

## 01-semi-automation-loop.png「半自動化からスキル改善へつながる循環」

```text
【サイズ】1600×900px（16:9）
【用途】「半自動化して、つまずいたらスキルに残す」章の理解を補助する循環図
【背景】白からごく薄いグレー。薄い技術グリッドを控えめに配置する
【構成】5つの角丸パネルを時計回りの矢印でつなぐ。「目的と材料」から始まり、「AIが途中工程」「人間が確認・確定」「手順と対処をスキルに残す」「次の仕事で改善」を経て最初へ戻る循環
【アイコン】目的と材料は人と資料、AIの途中工程はPCと書類、人間の確認・確定は人とチェックリスト、スキルはフォルダー、改善は上向きグラフ。成功とつまずきの両方からスキルへ矢印を入れる
【テキスト】「目的と材料」「AIが途中工程」「人間が確認・確定」「手順と対処を」「スキルに残す」「次の仕事で改善」。手順と対処を／スキルに残すは同じ黄色パネルに2行で表示し、ほかの余分な文字は入れない
【配色】白と薄いグレーを基調に、青緑、コーラル、ネイビー、学びを示す黄色をアクセントに使う
【雰囲気】落ち着いた日本語テックブログ向けのフラットな図解。800px幅でもラベルを読める太さと余白を確保する
【制約】企業ロゴ、製品ロゴ、書影、キャラクター、透過背景、余分な文章、透かし、黒い市松模様、過剰な発光、3D表現は入れない
```
